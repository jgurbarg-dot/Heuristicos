# App de Análisis de Heurísticas ⚙️

Esta es una aplicación web desarrollada con Streamlit diseñada para consultar heurísticas de Ingeniería Química, dividiendo el flujo entre las reglas de Seider (síntesis de procesos) y Walas (selección de equipos).

## Instrucciones para GitHub y Streamlit Cloud

1. Sube todos los archivos de este repositorio a GitHub.
2. **Importante:** Asegúrate de subir manualmente tus archivos PDF originales en la misma carpeta principal del repositorio, asegurando que los nombres coincidan:
   - `Seider - Capítulo 6.pdf`
   - `122 - Heurísticas _Walas (2012).pdf`
3. En [Streamlit Community Cloud](https://share.streamlit.io/), crea una nueva app apuntando a tu repositorio de GitHub.
4. Selecciona `app.py` como tu archivo principal (Main file path).
5. ¡Haz clic en Deploy!
